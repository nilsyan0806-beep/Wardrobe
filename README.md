# WARDROBE — Персональный виртуальный гардероб

Приложение для управления гардеробом, подбора образов и планирования покупок. Работает в браузере Safari и устанавливается на экран домой iPhone как нативное приложение. Все данные хранятся только на устройстве.

---

## Установка на iPhone

> ⚠️ Работает только через **Safari**. Chrome и другие браузеры не поддерживают установку PWA на iPhone.

1. Откройте ссылку приложения в **Safari**
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой ↑) внизу экрана
3. Выберите **«На экран домой»**
4. Нажмите **«Добавить»**

После установки приложение открывается без адресной строки, как нативное.

### Обновление

1. Сделайте **Экспорт** резервной копии (Настройки → Экспорт)
2. Удалите ярлык с рабочего стола
3. Снова откройте ссылку в Safari → добавьте на экран домой
4. **Импортируйте** резервную копию (Настройки → Импорт)

---

## Резервная копия

> ⚠️ Делайте экспорт регулярно — при удалении ярлыка данные могут сброситься.

**Экспорт:** Настройки → «⬇ Экспорт» → сохраните в «Файлы» → «На моём iPhone» → папка «Wardrobe»

**Импорт:** Настройки → «⬆ Импорт» → выберите файл `wardrobe-backup-ДАТА.json`

## Главная

- **Погода** — автоопределение по геолокации, кнопка «✏️ изменить» для ручного ввода города
- **Образ на сегодня** — подбирается с учётом температуры, осадков и ветра
  - 💙 **Сохранить** — добавить в «Мои образы»; автоматически покажется следующий
  - ↻ **Другой** — новый вариант
  - 👎 — пометить как несочетаемый (больше не предлагается)
- **Последние добавления** — нажатие на карточку = редактирование, ✕ = удаление

## Гардероб

### Добавить одну вещь (кнопка **+** вверху)
1. Выберите фото → откроется кадрирование (перетащите углы рамки)
2. Заполните: название, категория, сезон (можно несколько), стиль
3. «Добавить»

### Добавить несколько вещей (кнопка **⊞** вверху)
1. Выберите несколько фото → для каждой заполните поля
2. Нажмите на фото в очереди — кадрирование
3. «Добавить ещё» — загрузить дополнительные
4. «Добавить все»

### Редактирование
- Нажатие на карточку → редактирование (фото, название, категория, сезон, стиль)
- ✕ на карточке → удалить вещь
- В форме редактирования: «Заменить» — новое фото, «✂ Кадрировать» — обрезать текущее

## Луки

### Случайный образ
- Генерируется автоматически при открытии вкладки
- Может включать вещи из вишлиста (🛍 перед названием)
- 💙 **Сохранить** → образ сохраняется, автоматически показывается следующий
- ↻ **Другой** → новый вариант
- 👎 → добавить в несочетаемые

### Создать вручную (кнопка ✨ вверху)
- Прокрутите горизонтально фото вещей по категориям
- Нажмите на фото → выбрана (золотая рамка ✓); можно несколько в одной категории
- Вещи из вишлиста отмечены коричневой точкой
- Поле «Примечания» — необязательно

### Редактирование образа
- Кнопка ✏️ на карточке → редактировать
- Кнопка ✕ на карточке → удалить

### Фильтры «Мои образы»
1. По стилю: Все / Casual / Офис / Вечерний / Спорт / 🛍 С вишлистом
2. По сезону: Все сезоны / Весна-Осень / Лето / Зима
3. По вещи: сначала выберите категорию, затем конкретную вещь

## Шоппинг

- Подборка с **Wildberries** (фиолетовый WB) и **Ozon** (синий)
- Фильтры по категории; «↻ Обновить» — перемешать
- «Смотреть →» — открыть в браузере магазина
- «♥ Вишлист» — добавить в вишлист

---

## Вишлист

### Добавить вручную (кнопка ♥ вверху)
- Фото (с кадрированием), название, категория, сезон, магазин, цена
- Ссылка — кликабельна, поле авторасширяется и очищает лишний текст

### Фильтры
- По категории: Все / Верх / Низ / Обувь / Верхняя / Платья / Аксессуары
- По сезону: Весь год / Весна-Осень / Лето / Зима

### Редактирование: нажатие на карточку | Удаление: кнопка ✕

## Настройки

- **Резервная копия** — экспорт/импорт всех данных и фото
- **👎 Несочетаемые образы** — список с фото вещей; кнопка «Убрать» — снова предлагать

## Справочник

### Категории

| Категория | Что включает |
|-----------|-------------|
| Верх | Блузы, свитера, футболки, топы, рубашки |
| Низ | Брюки, юбки, джинсы, шорты |
| Обувь | Любая обувь |
| Верхняя одежда | Пальто, куртки, тренчи, пуховики |
| Платья/комбинезоны | Платья, сарафаны, комбинезоны |
| Аксессуары | Сумки, ремни, украшения, шарфы |

### Сезоны

| Сезон | Температура |
|-------|------------|
| Лето | +22°C и выше |
| Весна/Осень | +12°C — +22°C |
| Зима | Ниже +12°C |
| Всесезонный | Подходит всегда |

### Советы
- Фото на нейтральном фоне — лучше работает подбор образов
- Кадрирование убирает лишний фон
- Больше вещей → разнообразнее случайные образы
- Вещи из вишлиста участвуют в случайных образах — удобно проверить сочетаемость до покупки
- Делайте экспорт раз в неделю
